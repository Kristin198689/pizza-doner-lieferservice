# СТАРТ. Pizza / Döner / Yufka — архив для Claude Code

Этот ZIP — единый handoff-пакет: арт-дирекшн, визуалы, словари DE/EN/UK, конфигурация бизнеса, технический storyboard, ассеты и стартовый проект Next.js.

## Самое важное

- **Референс Hero утверждён пользователем**: `06_ASSETS/references/HERO_APPROVED_SCREENSHOT_IMG_1945.jpeg`. Использовать **именно его** как визуальную цель. На снимке виден интерфейс телефона; НЕ вставлять скриншот на сайт и НЕ копировать случайные кнопки или чужой брендинг.
- Главное: большая пицца справа, чёрный фон, дым, сырные нити, ингредиенты взлетают и падают; слева огромный белый заголовок и красное наклонное слово. Не заменять обычной пиццей из стока.
- На последующих скроллах: камера как бы поворачивается к другому ракурсу/пище, заголовки меняются; юфка выкатывается сбоку; переход как раскрывающаяся коробка.
- Настроение: кинематографичная еда + bold street food + editorial воздух. Много крупных пустот, минимальное число карточек.
- Цвета: угольно-чёрный, почти белый, насыщенный красный, светлый крафт, **одна** очень яркая лаймовая секция. Без пастельных цветов.
- Сайт не ресторан с посадочными местами; **Lieferung / Abholung**, основной заказ — **телефонный звонок**, не строить checkout и не обещать онлайн-оплату.
- Никаких свинины, бекона или свиных ингредиентов. Мясные фото генерированы и не подтверждают происхождение. Надпись HALAL только после подтверждения владельцем; сертификат не придумывать.
- НИКАКИХ придуманных отзывов, рейтингов, приложения, цен, точного меню, адреса, номера, часов, зоны доставки.
- Три языка: `de`, `en`, `uk` — немецкий по умолчанию. `uk` = украинский, не русский.

## Как передать Claude Code

1. Распакуй ZIP целиком в папку проекта (сохрани структуру).
2. Открой эту папку в Claude Code.
3. Скопируй текст из `00_START/CLAUDE_MASTER_PROMPT_RU.md` и отправь Claude.
4. Claude должен изучить файлы пакета, проверить исходники и начать работу. В папке `07_SITE_STARTER` есть стартовая реализация; её **можно улучшать**, а не переписывать вслепую.
5. Установить зависимости в `07_SITE_STARTER`: `npm install` → `npm run dev`. После этого Claude должен проверить сборку и весь сайт.

## Что является «готово», а что ещё зависит от клиента

**Готово в пакете:** визуальная концепция, выбор шрифтов/цветов/отступов, переводимые тексты интерфейса, структура страниц, наглядные PNG и примерные слои для анимации, концепт рабочего сайта, правила responsive / accessibility / SEO и детальный сценарий прокрутки.

**До публичного запуска нужны настоящие данные клиента:** бренд и логотип, телефон, адрес, часы, фактическое меню и цены, зона доставки, подтверждение статуса halal, юридические реквизиты и политика данных. Это НЕ должно блокировать начало разработки: use clearly marked placeholders, but never ship placeholders live.

**Техническая честность:** изображения пиццы собраны генеративно; лежащая и «взлетающая» пицца — разные независимые рендеры, а не покадрово согласованная 3D-модель. В архиве есть отдельные прозрачные topping sprites, но для идеальной бесшовности понадобятся ручная доводка и совмещение координат. Вертел PNG не является 3D-моделью; полноценный оборот вокруг оси требует GLB или нескольких ракурсов. Коробка одним PNG не будет физически открываться — требуется разделение крышки/основы либо простая 3D-модель.
