## 2. Storyboard новых сцен

### 3. Typography Takeover — FRISCH / HEISS
- Кадры: чёрный экран → «FRISCH» (белый, ~28vw) въезжает построчно из маски слева → «HEISS» (красный italic) справа, смещение по диагонали → кусок пиццы пролетает сквозь слова по дуге справа налево с поворотом, слова на миг «расступаются» (xPercent ±3) → пауза → слова гаснут, остаётся одна красная линия.
- Тексты: DE FRISCH / HEISS · EN FRESH / HOT · UK СВІЖЕ / ГАРЯЧЕ.
- Техника: GSAP timeline + scrub, SplitText-подобное разбиение по буквам вручную (свой код, без платных плагинов), transform/opacity.
- Мобайл: без pin; слова строятся при входе в экран (ScrollTrigger once), кусок пиццы пролетает за 1.2 с автоплеем.
- Reduced motion: статичные два слова + кусок пиццы в покое.
- Реализуемость: **высокая**. Нужен кусок пиццы **без свинины** (сейчас на слайсе пепперони, см. п. 5).

### 6. Döner Rotation (обожжённое дерево)
Честно: плоский PNG нельзя вращать вокруг вертикальной оси без обмана. Варианты:

| Вариант | Реализм | Что нужно | Вес | Рекомендация |
|---|---|---|---|---|
| A. «Цилиндрическая обёртка» (уже есть прототип `DonerSpit`) | средний, повторяется узор | текущий PNG, но нужен вертел крупнее (≥1000px высотой) | 0 | годится как запасной |
| B. **Turntable-кадры** 24–36 штук, scroll-scrub по canvas | **высокий** | 24–36 фото/рендеров вертела с одной точки при повороте на 10–15° | ~1.2 МБ (WebP) | **лучший результат**, нужны ассеты |
| C. **Three.js: настоящая геометрия** (конус из слоёв мяса) + текстура мяса из фото + нормали, динамический свет огня, частицы дыма | высокий, настоящий объём и свет | `three` (MIT, бесплатно), 1 текстура мяса (можно взять из PNG, лучше из крупного фото) | ~150 КБ gz | **рекомендую, если кадров нет** |

- Кадры сцены: приближение камеры к вертелу (scale 0.9→1.25 + лёгкий dolly), вращение привязано к скроллу (180°→540°), тёплый свет качается (огонь), дым поднимается слоями (спрайты `smoke_overlay`), искры (canvas-частицы), фон дерево с параллаксом, подпись «DÖNER» контуром за вертелом.
- Мобайл: вращение привязано к скроллу без pin (короткий диапазон ~120vh), без частиц.
- Reduced motion: один красивый кадр + статичная подпись.
- Реализуемость: **B — высокая при наличии кадров; C — средняя (2–3 дня работы), без внешних ассетов, но мясо будет «стилизованным»**. Нужно ваше решение.

### 7. FOOD ORBIT — подробно в п. 3.

### 8. Yufka Roll (лайм)
- Кадры: лайм-экран с гигантским чёрным словом «EINROLLEN.» → юфка выкатывается справа **с вращением вдоль оси движения** (x 120vw→0, rotation -360→0, как реально катится) → слова расходятся, как разорванные (две половины строки разъезжаются в стороны) → вторая строка «REINBEISSEN.» набегает по скорости скролла (kinetic type: skew и сдвиг по velocity) → короткая остановка.
- Техника: GSAP + `ScrollTrigger.getVelocity()` для кинетики. Всё на transform.
- Мобайл: без pin, 100–120vh. Reduced motion: статичный кадр.
- Реализуемость: **высокая**, база уже сделана.

### 9. Pizza Box — раскрытие
- Лучший вариант без новых ассетов: **CSS 3D-коробка**: основание и крышка — два прямоугольника с текстурой `kraft_cardboard.jpg`; крышка поворачивается на шарнире (rotateX 0→-115°) по скроллу, из-под неё поднимается пар (`smoke_overlay`) и выезжает пицца `pizza_hero_assembled.png`; экран крафта растёт и становится фоном следующей секции (меню).
- Запасной вариант: текущее маскированное раскрытие (`clip-path`), уже работает.
- Реализуемость: **средняя-высокая**. Лучше всего, если будут отдельные спрайты крышки и основания (не обязательно).
- Мобайл: короткий диапазон ~90vh; Reduced motion: открытая коробка статично.

## 3. FOOD ORBIT (новое меню-сцена)

**Идея.** Шесть блюд на прозрачном фоне стоят на невидимом овале: Pizza, Döner, Yufka, Burger, Pommes, Nuggets. Активное — спереди по центру, крупное; остальные уходят вглубь (меньше, темнее, выше по овалу). Перетаскивание мышью / свайп вращает орбиту, при отпускании она доезжает до ближайшего блюда (snap).

**Геометрия (DOM, без WebGL).** Для блюда i: угол `a = θ + i·60°`; `x = cx + rx·sin(a)`, `y = cy − ry·cos(a)·0.35`, `depth = (cos(a)+1)/2`; `scale = 0.45 + 0.75·depth`, `opacity = 0.35 + 0.65·depth`, `z-index = round(depth·10)`. rx ≈ 38vw, ry ≈ 22vh. Только `transform` и `opacity`.

**Взаимодействие.**
- Pointer Events (мышь + тач), `touch-action: pan-y` → вертикальный скролл страницы не блокируется, горизонтальный свайп крутит орбиту.
- Инерция + snap: GSAP (Draggable/InertiaPlugin сейчас бесплатные), либо свой код — решим по размеру бандла.
- Клик/тап по блюду на заднем плане делает его активным.
- Стрелки ← → на клавиатуре, кнопки «назад / вперёд» (44px), `aria-live` объявляет активную категорию.
- Быстрый свайп: максимум один шаг на жест на мобильных (никаких «пролётов» через три блюда).

**Типографика (без наложений).**
- Название активной категории — огромное, **под орбитой** (отдельная строка в потоке, не поверх фото); при смене — маска-перелёт по буквам.
- Одна строка подсказки + кнопка «Zur Speisekarte ↓» (якорь на раздел этой категории в полном меню).
- Названия неактивных блюд **не показываем**: нет шанса наложения.
- Фон: пыль/искры (лёгкий canvas, ≤ 40 частиц, отключается на слабых устройствах).

**Мобайл:** орбита меньше (rx 34vw, ry 14vh), активное блюдо ~70vw, название под ним, под ним точки-индикаторы.
**Reduced motion:** горизонтальный ряд (scroll-snap) без 3D-глубины, то же управление.
**Без JS:** список из 6 ссылок на разделы меню.

## 4. Полное меню (editorial, без карточек)

**Макет (desktop):** слева липкая колонка с номером и названием категории (`01 PIZZA`, огромными буквами), справа — строки блюд: название · состав (мелко) · пунктирный лидер · цена (или «Preis folgt»). Между категориями — по одной крупной фотографии, выходящей за поле (без рамок и фонов). Фильтр — не нужен: якоря и синхронизация с орбитой.
**Макет (mobile):** категория — крупный заголовок, ниже плотные строки блюд, цена справа; без аккордеонов.
**Поверхность:** предлагаю **крафт-бумагу** (читаемость длинного текста + логичное продолжение раскрытой коробки). Вариант — чёрный фон, белый текст. Нужен ваш выбор.

**Данные (управляются из одного файла `src/content/menu.json`):**
```json
{
  "currency": "EUR",
  "pricesConfirmed": false,
  "categories": [
    {
      "id": "pizza",
      "name": { "de": "Pizza", "en": "Pizza", "uk": "Піца" },
      "note": { "de": "", "en": "", "uk": "" },
      "items": [
        {
          "id": "pizza-margherita",
          "name": { "de": "…", "en": "…", "uk": "…" },
          "description": { "de": "Tomate, Mozzarella …", "en": "…", "uk": "…" },
          "variants": [{ "label": "26 cm", "price": null }, { "label": "32 cm", "price": null }],
          "tags": ["vegetarian"],
          "allergens": [],
          "available": true
        }
      ]
    }
  ]
}
```
- `price: null` или `pricesConfirmed: false` → показываем «Preis folgt» / «Price to follow» / «Ціна буде додана».
- Категории: Pizza, Döner, Yufka, Burger, Snacks (Pommes, Nuggets), Getränke. Реальные блюда и цены — только от владельца; пока в файле структура и пустые позиции-заглушки.
- Один JSON → шаблон для разных пиццерий: заменяют файл, картинки и `business.json`.
